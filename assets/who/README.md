# WHO reference tables

`bmi_for_age_2007.csv` — WHO 2007 Growth Reference, BMI-for-age 5–19 years,
expanded (monthly) LMS tables for boys and girls, combined into one file:

```
sex,month,L,M,S
1,61,...
```

`sex`: 1 = boys, 2 = girls. Months 61–228.

The values must be copied unmodified from the official WHO files
(https://www.who.int/tools/growth-reference-data-for-5to19-years). Never
type them in by hand. While the file is absent, the app shows no
classification for ages 5–19 instead of a guessed one.
